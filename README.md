# Nawasara Docs

In-app component gallery and code examples for the Nawasara UI library. Browse every shared Blade component, see usage snippets, and copy the markup.

## Features

- **Component gallery** — buttons, modals, tables, forms, badges, dropdowns, and the rest of `nawasara/ui` rendered with their canonical examples
- **Copyable code snippets** — every example shows the source so developers can paste it into their own pages
- **Searchable** — filter components by name or category
- **Lives at `/docs`** — accessible to logged-in developers; permission-gated

## Installation

```bash
composer require nawasara/docs --dev
```

Auto-discovered. The route registers under `/docs`.
